# odin-recipes
Recipes HTML project for Odin

The recipes HTML project for Odin consists of basic HTML coding to create a series of webpages of different recipes with pictures, descriptions, and ingredients.
With the completion of the recipes project for Odin, I have demonstrated a complete understanding of basic HTML functions such as setup (headers, body, paragraphs, etc), images, lists, links, and much more.
The project may be viewed by running the command `explorer.exe index.html` in the directory containing the project (for WSL2).
